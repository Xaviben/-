如何让手机点开/分享给别人？

方法一：生成永久在线链接（推荐，随时随地可用）

您可以将代码免费托管到以下平台，生成一个网页链接，发到微信群，手机点击即可直接查看：

  • GitHub Pages / Vercel / Netlify：新建一个仓库上传本代码，几秒钟即可获取专属链接。
  • 静态托管小工具：如 静态网页托管 或其他云服务平台，拖入 index.html 即可。

方法二：局域网直接在手机上打开

如果电脑和手机连了同一个Wi-Fi：

  1. 将本代码保存为电脑桌面上的 index.html 文件。
  2. 在电脑上用命令行（如终端/CMD）运行一个简易服务器（例如在文件目录下运行 python -m http.server 8000）。
  3. 在手机浏览器输入电脑的局域网IP地址（如 http://192.168.x.x:8000）即可点开！

方法三：文件传输至手机打开

点击下方按钮复制本页面的全部完整代码，在手机上新建一个文本文档，把后缀名改为 index.html，然后用手机自带浏览器打开即可完美运行！
